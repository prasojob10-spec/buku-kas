Tentang akses, penyimpanan, dan anggota

Untuk menambah anggota: buka spreadsheet → Bagikan → masukkan Gmail anggota → pilih Editor. Selama aplikasi berstatus Testing, tambahkan Gmail yang sama di Google Auth Platform → Audience → Test users.

Aplikasi memakai izin Google Sheets untuk membaca dan menulis spreadsheet yang dikonfigurasi. Izin OAuth Sheets mencakup spreadsheet yang dapat diakses akun Anda; aplikasi ini hanya mengirim permintaan ke ID dalam config.js. Token akses hanya disimpan di memori selama halaman terbuka.

Perubahan tersimpan sebagai riwayat pada tab “Buku Kas”. Edit dan hapus melalui web; jangan mengubah, menyortir, atau menghapus baris riwayat secara manual. Gunakan CSV dari web untuk daftar transaksi yang berlaku. Cache dan antrean disimpan pada perangkat ini per akun dan spreadsheet.
